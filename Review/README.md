# Comparações da revisão visual

`*-antes.png`: HTML do commit `e56e628`, correspondente à versão publicada anteriormente. `*-depois.png`: revisão atual. As capturas usam a mesma largura de painel, preset Default e dispositivo @2x; somente a prévia da agulha foi fixada a 12° para permitir comparação do desenho. A medição real do plugin não foi alterada.

As capturas não são fotografias do plugin original nem uma comparação automatizada pixel a pixel com a referência anexada. Consulte [UI_CHANGES.md](../UI_CHANGES.md) para os valores e decisões usados.

`presets-windows.png` é uma captura do navegador nativo produzida pelo executável Windows no Wine, usando a fonte Inter incorporada; os filtros foram limpos pelo teste. Não representa uma sessão em DAW Windows real.
